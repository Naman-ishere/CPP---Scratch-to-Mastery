# C++ - Scratch to Mastery

This repository contains beginner-level practice programs focused on C++ fundamentals, pattern printing, loops, and basic problem-solving. The exercises are mostly under the `C++ Basics` folder and cover repeated logic building with `for` loops and nested loops.

## Included practice files

The following source files were included in the summary and are part of the learning work:

### Pattern and number-printing exercises

- [C++ Basics/FloydTriangle.cpp](C++%20Basics/FloydTriangle.cpp)  
  Prints Floyd's Triangle using a running number counter.

- [C++ Basics/hollowHeera.cpp](C++%20Basics/hollowHeera.cpp)  
  Attempts a hollow pattern design with nested loops and spacing.

- [C++ Basics/invertedTrikonPattern.cpp](C++%20Basics/invertedTrikonPattern.cpp)  
  Prints an inverted triangle using repeated values.

- [C++ Basics/numPyramid.cpp](C++%20Basics/numPyramid.cpp)  
  Creates a mirrored number pyramid.

- [C++ Basics/pattern1.cpp](C++%20Basics/pattern1.cpp)  
  Prints a square pattern using numbers from 1 to n.

- [C++ Basics/pattern2.cpp](C++%20Basics/pattern2.cpp)  
  Prints a square star pattern.

- [C++ Basics/pattern3.cpp](C++%20Basics/pattern3.cpp)  
  Prints a continuous number square pattern.

- [C++ Basics/pattern4.cpp](C++%20Basics/pattern4.cpp)  
  Prints a right-angle star triangle.

- [C++ Basics/pattern5.cpp](C++%20Basics/pattern5.cpp)  
  Prints a triangle with repeating numeric values.

- [C++ Basics/pattern6.cpp](C++%20Basics/pattern6.cpp)  
  Prints a triangular number pattern with incremental numbering.

- [C++ Basics/pattern7.cpp](C++%20Basics/pattern7.cpp)  
  Prints a reverse number triangle.

### Loop and logic practice

- [C++ Basics/pq1forloop.cpp](C++%20Basics/pq1forloop.cpp)  
  Calculates the sum of odd numbers from 1 to n.

- [C++ Basics/pq2forloop.cpp](C++%20Basics/pq2forloop.cpp)  
  Calculates the sum from 1 to n.

- [C++ Basics/pq3loops.cpp](C++%20Basics/pq3loops.cpp)  
  Checks whether an input number is prime.

### Small Python practice files

- [C++ Basics/bakchodi.py](C++%20Basics/bakchodi.py)  
  Simple Python program to add two integers entered by the user.

- [C++ Basics/pattern7.py](C++%20Basics/pattern7.py)  
  Python version of a reverse number triangle pattern.

## Skills practiced

- C++ syntax and I/O
- `for` loops and nested loops
- Pattern design using spaces and stars
- Numeric pattern generation
- Arithmetic accumulation
- Prime number checking
- Simple Python basics for comparison and practice

## Quick run examples

Compile a C++ file:

```bash
g++ C++\ Basics/FloydTriangle.cpp -o FloydTriangle
./FloydTriangle
```

Run a Python script:

```bash
python "C++ Basics/pattern7.py"
```

This set of files represents an early-stage foundation in C++ and pattern-based problem solving. The focus was on understanding nested loops, structure, and logic flow before moving into more advanced DSA topics.
